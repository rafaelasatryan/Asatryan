Учебный проект по веб-разработке, выполненный в рамках обучения от компании Интерволга.

Технологии:
PHP, MySQL, HTML, CSS, JavaScript, Bootstrap 5.

Функциональность:
Работа с базой данных MySQL.
CRUD-операции (добавление, просмотр, редактирование и удаление записей).
Работа со связанными таблицами.
Загрузка и удаление изображений.
Импорт и экспорт данных в CSV, XML и JSON.

Структура:
LR1–LR7 — последовательные этапы разработки проекта.
